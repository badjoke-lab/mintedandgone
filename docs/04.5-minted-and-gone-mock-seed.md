## 0. この文書の役割

この文書は、HTMLモックを作るための **小さいseed sample** を定義する。

このseedは正式な `marketplaces.json` ではない。  
このseedはUI確認用であり、公開データではない。

目的:

```txt
トップページのFeatured / Recently gone表示を確認する
一覧ページのカード表示を確認する
status chip の見た目を確認する
category / chain / marketplace_scope の見え方を確認する
詳細ページの facts / what remains / timeline / evidence を確認する
Methodology / About との視覚差を確認する
statsページを作る場合の最小KPI表示を確認する
```

## 1. Mock seed files

HTMLモック用に以下のファイルを作る。

```txt
mock-data/mock-marketplaces.json
mock-data/mock-events.json
mock-data/mock-evidence.json
mock-data/mock-stats.json
```

正式実装時には以下へ変換する。

```txt
data/marketplaces.json
data/events.json
data/evidence.json
data/stats.json
```

ただし、変換前に必ずsource確認・archive確認・status確認を行う。

## 2. Mock seed policy

## 2.1 件数

HTMLモック用seedは **12 records** にする。

理由:

```txt
少なすぎると一覧・statsが確認できない
多すぎるとモック作成前にデータ作業が重くなる
12件あればstatus / category / chain / card layout を確認できる
```

## 2.2 status coverage

12件で以下を一通り見る。

```txt
active
limited
inactive
dead
acquired
merged
rebranded
unknown
```

## 2.3 UI coverage

12件で以下のUIパターンを確認する。

```txt
active major marketplace
closed marketplace
CEX NFT marketplace
art curated marketplace
chain-specific marketplace
aggregator
community continuation
brand marketplace
metaverse/gaming marketplace
unknown / needs review
```
