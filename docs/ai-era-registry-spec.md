# MAG AI-era Registry Specification

Status: planned / mandatory future-work reference

## Goal
MAG must remain useful beyond generic NFT-marketplace summaries by preserving evidence-backed marketplace lifecycle, closure aftermath, migration and successor history.

## Required work
- Preserve current v0 schema/methodology and reviewed evidence boundaries.
- Follow marketplace lifecycle where supported: launch -> major change/decline -> shutdown -> acquisition/migration -> successor/current outcome.
- Improve provenance, archive, confidence, last-verification and unresolved-uncertainty visibility.
- Provide deterministic per-marketplace machine-readable JSON derived from canonical entity/event/evidence data.
- Strengthen structured filters for chain, status, closure/change reason, year, successor/migration and evidence quality where supported.
- Add Compare focused on historical/lifecycle differences.
- Add Stats for closure/change reasons, marketplace lifespan, chain distribution, migration/successor outcomes and registry coverage/quality.
- Do not auto-promote discovered candidates into canonical records.

## Non-goals
No NFT price/ranking dashboard, AI-generated canonical history, prompt buttons or chatbot-first UI.

## Mandatory reference
Future MAG schema, implementation, record-growth, quality, machine-readable, Compare and Stats work must consult this file together with existing v0/design/methodology documents.
